Baixar o programa Cone Manutenção

Procurando a versão mais nova…

  1. Feche o Cone Manutenção, se estiver aberto.
  2. Abra o arquivo baixado (Cone-Manutencao-Instalador-…exe). Se o Windows avisar, clique em Mais informações › Executar assim mesmo.
  3. Os dados ficam no computador e não são apagados ao instalar uma versão nova.
